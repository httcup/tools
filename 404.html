这个页面不在这儿

要么地址打错了，要么原来在这儿的东西挪了地方。你的文件没事，也没丢掉什么。本站从来没拿到过你的东西，想丢也无从丢起。

全部工具，都在这儿

全部免费，都在浏览器里处理文件。

  • 图片压缩 你说要多大，100 KB、2 MB 都行，它去找刚好够到这个数的最轻一档压缩。
  • 图片缩放 精确到像素、按百分比，或者定个长边，顺路还能裁一刀、换个格式。一张图或者一整个文件夹都行。
  • Image Layout Make a collage, a contact sheet, or a horizontal or vertical strip. Reorder the pictures, set the gaps, and save one PNG, JPEG or WebP.
  • HEIC 转 JPG iPhone 拍的照片，换成什么都打得开的格式。解码在你自己的机器上，不在谁的服务器上。
  • WebP 转 JPG 把网页保存的图片变成所有软件仍然接受的格式。在你的设备上转换，透明区域填充你选择的颜色。
  • PNG 转 WebP 同一张图片，常常减少三分之一体积。需要保留像素就选无损，否则可以更小。透明区域在两种模式中都保留。
  • AVIF 转 JPG 从网站保存的图片没有软件能打开？浏览器已经能读取 AVIF，本工具直接在你的设备上把它转为 JPG，文件不会去往别处。
  • 证件照制作 选一个国家和一种证件，裁切框就会按那条规定取头高和眼线。按精确的毫米和分辨率打印，附带 ⁦10 × 15⁩ 拼版，并把上传文件压进办事门户的 KB 区间。
  • 图片堆栈 把一串连拍合成一张：取平均值抹掉噪点，取中位数甩掉路人，或者取最亮做星轨。RAW 文件不用转换器也读得了。
  • 图片涂黑与打码 把图片的一部分涂黑、打码或者模糊掉。被遮的像素在文件写出来之前就被覆盖，不会留下一层可以挪开的东西。
  • EXIF 查看与清除 看清一张照片里藏着的位置、相机和机身序列号，想改哪条改哪条，或者一键清光。
  • DICOM 阅片器 DCM 文件打开工具：在你自己的机器上打开 CT、MR、X 光或超声影像。调好窗宽窗位，翻完整套序列，按毫米测量，读遍头信息里的每一个标签。
  • 图片转 ICO 网站图标、Windows 应用图标，或者 macOS 的 .icns，每个尺寸都装在一个文件里，下载前先看 16 像素下什么样。
  • 图片转 Data URI 位图走 base64，SVG 走百分号编码，外面那圈 CSS 规则或者 <img> 标签也一并写好。
  • SVG 转图片 SVG 自己没有像素尺寸，所以这个数字由你定，32 也好 8000 也好，一样锐利。
  • 图片转 SVG 放大的位图是一段楼梯。轮廓是一条指令，所以任何尺寸都锐利，前提是你手里的是个形状，不是照片。
  • 身高对比图 把两个大人、一个孩子和一道门放在同一把标尺上——用厘米或者英尺英寸——然后下载成 PNG 或 SVG。
  • 商家资料预览 你的 Google 商家资料会长成什么样：知识面板、手机上的卡片，以及本地搜索结果。已经有一份的话，粘贴进来就能作为起点。
  • 视频压缩 说一个文件最多能有多大，8 MB、25 MB、现在的一半，工具就选好画面尺寸和码率，在你的机器上重新编码画面，把声音原样复制过去，然后拿结果对着那个数字量一遍，再给你下载。
  • MP4 转换 录屏出来的 WebM、压制出来的 MKV、相机拍的 MOV，重新写成 MP4 里的 H.264 和 AAC，也就是什么都收的那种文件。已经是 H.264 或 AAC 的部分原样复制过去，只有不是的部分才在你的机器上重新编码。
  • 视频旋转 往右或往左转四分之一圈，或者倒过来，给那些拍横了的片段。使用文件头旋转时，每一帧画面原样复制；为老播放器把旋转烧进画面时，画面会重新编码。声音会原样复制、重新编码为 AAC 或去掉。
  • 图片转视频 把一个文件夹的图片做成 MP4 幻灯片。编码在你自己的机器上跑，用的是你自己的硬件。
  • 视频剪切 标记要保留的片段并保存为一个视频。选择范围允许时，复制模式保留画质；精确剪切会重新编码画面。
  • 视频裁剪 在片子上拉个框，切到只剩这块。发帖用方的，手机上看用竖的，或者精确到像素填一个框。
  • 视频倒放 把片子反过来放，画面和声音都算在内，而且不用把它发到任何地方去。
  • 延时视频 把长片子变成短片子，几小时压成几秒钟，而且不往任何地方送。
  • 视频截帧 把视频的任意一帧存成图片，尺寸就是视频本身的尺寸。可以一张一张地截，也可以每隔几秒截一张。
  • GIF 转 MP4 同一段动画变成 MP4，通常只有十分之一大，给那些不收大 GIF 的地方。每一帧保留 GIF 给它的延时，不做重采样，画面尺寸不变。在你的机器上编码。
  • 视频转 GIF 标出你要的那几秒，挑好宽度和帧率，拿到一张 GIF 动图，配色板、抖动一并办好。
  • GIF 制作 把图片排好顺序，说清楚每张停多久，就能拿到一个 GIF 动图。颜色和压缩都是在你自己的机器上算出来的。
  • GIF 拆帧 把动图拆开：每一帧存成单独的 PNG，透明保留下来，时长另外记下。解压 GIF 这件事发生在你自己的机器上。
  • GIF 分析 打开一个 GIF，看看里面到底有什么：每一帧的延时和处置方式、颜色表，以及一份关于体积去了哪里的老实账。
  • PDF 合并与拆分 把文档拼起来，把一个切成好几个，把页面拖成你要的顺序。链接和书签会重新搭好，跟着它们指向的页面走；每一个成品文件在交给你之前，都会被重新打开、重新数一遍页数。
  • PDF 压缩 把文档里的图片重新压一遍，文件就小了。它先摆给你看体积到底压在哪儿，没什么可省的时候也直说。
  • PDF 解锁 在本地移除 PDF 权限限制，或移除你提供的打开密码。页面会先识别文件的保护类型，再请求密码。不上传内容，也不猜测密码。
  • PDF 加密 给 PDF 加上密码，或者请阅读器别打印、别复制，文档哪儿都不用去。默认 AES-256，老阅读器另有一个老方案，做好的文件会先在这里重新打开一次、证明锁得住，然后才给你。
  • PDF 水印 在 PDF 的每一页上盖上「这是给谁的」、一个日期或者一个名字，任意角度和透明度，任何语言，文档哪儿都不用去。页面本身不动，做好的文件会在这里重新打开一次，证明每一页都盖上了。
  • PDF 涂黑 把词从 PDF 里删掉，而不是盖住。字是从绘制这一页的指令里拿走的，空出来的宽度保留着，别的东西不会移位；做好的文件还会在这里重新打开搜一遍，证明那些词不在里面。
  • PDF 转 CSV 在浏览器中将含文本的 PDF 表格提取为 CSV，适用于账单、发票、价目表和报告。检测依赖可读取文本的位置，可能遗漏特殊布局；扫描页需先进行 OCR。不会上传文件。
  • 收据与发票识别 在设备上识别收据和发票照片，核对建议字段，再整理每笔金额、单据数量和统一币种总额。汇率可手动填写，也可选择查询在线历史汇率。裁剪、压缩图片后发送邮件，或将报告保存为 CSV。
  • 图片转 PDF 把图片合成一个 PDF，一张一页。JPEG 照片原样抄进去，画质一点不掉。
  • 文档扫描 一张纸的照片，摆正清理之后变成一份文档。四个角替你找好，倾斜给你掰正，阴影除掉。
  • 从视频里提取音频 拖进一个 MP4、MOV 或 WebM，把声音单独存下来。只有音轨会被解码，画面从不读取，文件也不离开你的设备。
  • 音频剪辑 边听边把值得留下的段落标出来，然后存成一段录音。切点落在精确的采样上，接缝也不会咔哒。
  • 音频编辑 倒放一段音频，变速时音高可动可不动，把录轻了的录音提上来。视频里的声音也能抽出来。
  • JSON 格式化 格式化和压缩 JSON、XML、HTML、CSS 和 YAML，或者在它们之间转换。贴个 token 或者一份配置文件，不用交给任何人。
  • YAML 转 JSON 把 YAML 变成 JSON，或者把 JSON 变成 YAML，并且让它告诉你这趟的代价。粘一份部署配置，不用交给任何人。
  • XML 格式化 把 XML 排开好读，压平好发，或者转成 JSON 再转回来。粘一张发票或者一个订阅源，不用交给任何人。
  • 文本比对 比对两段文本，逐行、逐词看清改了什么。贴一份合同或者尚未发布的代码，不用交给任何人。
  • Base64 编码解码 Base64、URL、HTML 实体、十六进制和反斜杠转义，编码或解码。贴个 token，不用交给任何人。
  • 二维码与条形码生成 给链接、Wi-Fi 或者名片做个二维码，也可以做一个算好校验位的零售条码。SVG 或 PNG 随你拿。
  • 二维码与条形码识读 从照片、截图或摄像头读二维码，并在打开之前看到完整地址。条形码也行。
  • 哈希与校验和 算出文件的 MD5、SHA-1、SHA-256、SHA-384 或 SHA-512，再和下载页面公布的值对照。多大都行：文件是分块读的，从不整个留在内存里。
  • 密码与密码短语生成器 一个强随机密码，或者用自带词表拼出来的密码短语。由你自己的浏览器抽取，不发往任何地方。
  • 文本与文件分享 从打开的浏览器加密分享文本与文件。默认直连，也可选择云中转。你可以逐一批准读者。
  • Local Walkie-Talkie One browser host and up to ten receive-only listeners, with push to talk and automatic reconnection.
  • Voice Oncall Several people send live voice to one host, with nearby discovery, an optional password and individual moderation.
  • Remote Camera A phone or computer camera in another browser, with optional viewer approval, camera switching and encrypted video over Direct or Cloud relay.
  • Share a Browser Tab Encrypted live tab video for one approved viewer, using Direct or Cloud relay. Invite by link, network discovery or a private group. No extension, sound or remote control.
