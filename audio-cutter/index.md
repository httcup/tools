# 在线音频剪辑

把录音、播客、配乐拖进来，波形一眼看清：拖动选一段，裁剪保留、删除不要、选区静音、加淡入淡出、调音量、按峰值标准化，最后导出无损 WAV（16 / 24 / 32 位可选）。

文件在你的浏览器里用 WebAudio 解码，采样点直接改，不上传服务器。

## 用法

1. 拖入或选择音频文件（mp3 / m4a / aac / wav / ogg / flac / opus）；
2. 在波形上按住拖动选中一段，双击清除选区；
3. 「裁剪保留选区」只留选中部分，「删除选区」把选中部分挖掉，「选区静音」保留时长但静音；
4. 淡入 / 淡出默认作用在选区，没选就作用整段；音量 ±3 dB、峰值标准化一键处理；
5. 选位深后「导出 WAV」，也可以「只导出选区」单独存成一段。

## 提示

- 导出是无损 PCM，比再压一次 mp3 更保真，代价是文件变大；需要 mp3 请用编码器另转；
- 单轨粗剪够用；多轨混音、降噪、变速变调建议用桌面软件；
- 每次操作都会存一步撤销（最多 12 步），剪坏了点「撤销上一步」；
- 空格键可以播放 / 暂停，编辑时按空格仍是输入空格。
