# 报名证件照处理

考试报名系统对照片卡得最死：宽高要精确到像素（如 480×640），格式要 JPG，体积要卡在 KB 区间（如 20–40KB）。这里按报名要求填宽高和最大体积，拖框把人像裁正，自动压缩到 KB 以内输出 JPG，直接上传过审。

照片只读进浏览器本地处理，不上传任何数据。

## 用法

1. 选常见规格（一寸 295×413、二寸 413×579、480×640 等）或手动填宽高，填最大体积 KB；
2. 选择证件照原片，拖动选框调整位置，拖四角缩放（自动保持宽高比）；
3. 点「生成证件照」，右侧预览成品的实际像素与体积；
4. 点成品图或「下载 JPG」保存，传到报名系统。

## 提示

- 体积留点余量更稳：要求 20–40KB 就填 38，别顶格；
- 生成结果低于体积下限（如要求 ≥20KB 只出了 15KB）时，换更清晰的原片，或把宽高按比例调大重新生成；
- 背景色不合要求（要白底/蓝底/红底）先去 [证件照换底色](../id-photo-bg/) 处理，再回来裁尺寸；
- 原片越清晰，压缩后越不糊。
