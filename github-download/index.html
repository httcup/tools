GitHub 仓库文件下载

只要一个文件夹，不想装 git 也不想克隆整个仓库？粘贴仓库、目录或文件链接，浏览器直连 GitHub 拉取内容，整个文件夹打包成 ZIP 下载。文件从 GitHub 直达你的浏览器，本工具没有后端。

私有仓库 / 提速率限制（可选）

Token 只在本次请求里发给 api.github.com，不保存、不经过第三方。未登录限 60 次/小时。

    数据怎么走

    文件列表来自 api.github.com，文件内容来自 raw.githubusercontent.com，全程浏览器直连 GitHub，ZIP 在你的浏览器里打包，没有中间服务器能碰你的文件。未登录每小时限 60 次请求，大目录建议配 Token。

    支持什么链接

    仓库主页（下整库）、/tree/分支/路径（下目录）、/blob/分支/路径（下单文件）。默认分支可省略。私有仓库或超限就填一个只读 Token。
