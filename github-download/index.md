# GitHub 仓库文件下载

只要仓库里的一个文件夹，不想装 git、不想克隆整个仓库？粘贴仓库、目录或文件链接，浏览器直连 GitHub 拉取内容，整个文件夹打包成 ZIP 下载。

文件从 GitHub 直达你的浏览器，ZIP 也在浏览器里打包，本工具没有后端。

## 用法

1. 粘贴链接，支持四种：
   - 仓库主页 `github.com/用户/仓库` —— 下整库
   - 目录 `github.com/用户/仓库/tree/分支/路径` —— 下这个文件夹
   - 文件 `github.com/用户/仓库/blob/分支/路径` —— 下单文件
   - SSH 地址 `git@github.com:用户/仓库.git` 也认
2. 「获取文件列表」→ 确认文件清单 → 「打包下载 ZIP」；
3. 私有仓库或触发限流时，展开「私有仓库 / 提速率限制」填一个只读 Token。

## 提示

- 未登录 GitHub API 限 60 次/小时；列表请求只占 1–2 次，主要开销在文件内容（走 raw 直链，不占 API 配额），几百个文件一般没问题；
- 超大仓库（几万个文件）会超过列表 API 上限，请缩小到子目录；
- Token 只在本次请求头发给 api.github.com，不保存、不经过任何第三方。
