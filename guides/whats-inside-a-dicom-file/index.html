# DICOM 文件里都装着什么？

装的不只是扫描。DICOM 文件是一份夹着图像的病历：你的姓名、出生日期和住院号，和像素坐在同一个文件里。这件事最要紧的时刻，恰恰是有人把一张光盘塞进你手里、你出门去找看图软件的那一刻。

最后更新 2026年10月13日

## 先说结论

DICOM 文件，医院递给你的光盘上那个 `.dcm`，不是 JPEG 那样的图像格式。它是病历格式，图像只是夹在里面。像素开始之前，文件先驮着一个几百条标签的文件头，里面照例写着：患者全名、出生日期、性别、住院号；检查的日期、时刻和描述；开单医生；机构和设备，细到序列号；还有一组独一无二的标识符，充当一路回到生成它们的影像库的钥匙。

图像亮在屏幕上的时候，这些一样也看不见，也正因此被忘得干干净净。扫描就是病历。请按它是的那份文件对待它，别按它装的那张图对待它。

## 第二意见和教学，需要不同副本

**第二意见。**问接收诊所怎样传原研究。本地查看可了解资料，但别临时自创去标识步骤，可能删临床背景。单切片截图不能替代研究。

**教学或研究。**取得为该用途批准并经过适当去标识的副本，头部和像素都检查，识别字可能烧在图里。[DICOM 保密配置](https://dicom.nema.org/medical/dicom/current/output/chtml/part15/chapter_E.html)包括属性和额外清理选项，并明确不保证信息对象完全去标识。

兼容问题可能只需编码名或错误。完整头部报告带患者标识时别附公开问题单。查看器读取字段，不删除。

## 偏偏是这个文件，为什么传得这么随手

陷阱在现实里是这么落地的：检查完，病人拿到一张光盘或一个下载，想打开，机器上什么都打不开。DICOM 不是寻常软件认得的格式。于是去搜“在线打开 dcm 文件”，搜出来的多半是个上传框。片刻之后，一份完整的、带着身份的病历，姓名、出生日期、住院号、透着诊断意味的检查描述，一样不少，躺在了那天谁排名靠前谁家的服务器上。

看看这个轮廓：又是证件照那一出。敏感文件，一个卡壳的瞬间，一个搜索引擎。只是这回的文件敏感了两层。护照漏的是你是谁；扫描漏的是你是谁，*外加在查什么*。上传的一般道理有[自己的一页](https://httcup.github.io/tools/guides/is-it-safe-to-upload-files/)；而这个文件，是那套道理一滴佐料都不用加的那种。

在本地把文件打开，就是全部的药方，这里的 [DICOM 查看器](https://httcup.github.io/tools/dicom-viewer/)就是干这个的：扫描本身，真正的窗宽窗位调节，一个文件夹重新码回它的序列，毫米计的测量，文件头每条标签都读得到。而且什么都不离开你的机器。分步的做法在[打开指南](https://httcup.github.io/tools/guides/open-a-dicom-file/)里。

## “名字我删了”不等于去标识

下一个错更细，出发点也更好：把最显眼的标签删掉，就把扫描分享出去了。给要第二意见的服务，给研究者，给论坛。这有多不够，标准自己说得毫不客气。DICOM 自带的去标识配置列出了数据集敢称去标识之前必须处理的标签，一列就是*几百*条，因为身份住的地方远不止姓名那一格：

- **名字之外的直接标识**：出生日期、患者号、检查号、医生和机构的名字。
- **钥匙**：盖在每个文件上的唯一标识符。它们不说你是谁，却对任何见过原件的系统说得分毫不差：*你是哪一份病历*。
- **半个身份的线索**：检查的日期时刻、设备型号和序列号、部位、患者年龄。单看模糊，凑齐就窄。
- **像素本身**：超声等一些检查方式把患者姓名直接烧进图像里，那是任何标签编辑都够不着的地方。（导出的图片要处理这个，是[像素级涂抹](https://httcup.github.io/tools/redact-image/)的活，不是元数据工具的活。）

所以这里的查看器带着一块面板，逐条列出你的文件里有什么在指认患者、指认得有多直接，就是按标准自己那份清单搭的。也所以这个查看器只*读*：它没有一行写 DICOM 文件的代码，因为“已匿名化”这个承诺的门槛，远比一个查看器迈得过去的高。把这种承诺兑现一半的工具，比从不许诺的更糟。

## 把扫描当它本来就是的病历来待

习惯从上面这些里自己长出来：

- **本地查看。**断开 Wi-Fi 还能工作的查看器，证明了这次处理可以在本地完成。本站工具可以。光盘自带查看器如果在自己的设备运行，也可使用。
- **医疗用途通过医疗渠道分享。**向另一家医院发送检查，有相应的可追责基础设施。私人邮件附上装有 `.dcm` 的 `.zip`，则会在邮件服务器上留下病历副本。
- **分享前弄清内容。**读取文件头和身份面板，让传出的信息是你的决定，而不是意外。“妥善去标识”应与影像机构或接收方讨论具体流程，不是自行临时勾一个框。
- **光盘会比办事存在得更久。**下载文件夹的副本和抽屉里的 CD，同样是完整病历，像那份没人记得删除的证件扫描。

这些没有一条说扫描永远别分享。第二意见，本来就是副本存在的理由。要说的是：这个文件是一份关于你的文件，所以这组指南翻来覆去落到的那两个问题，在这儿同样是对的问题：交到谁手里，以及这一交，究竟非交不可吗。
