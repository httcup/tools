# 照片要求：日本居留卡

出入国在留管理庁 对这种证件的照片有什么要求，以 2026-09-21 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-21

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦30 x 40⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 55.0% 到 70.0%（⁦22–28⁩ mm） |
| 眼睛高度，从底部量 | 45.0% 到 60.0%（⁦18–24⁩ mm）（参考） |
| 背景 | 素净而浅——没公布颜色 |
| 上传规定 | 没有公布——这一条是给打印的 |

[按这条规定制作照片](https://httcup.github.io/tools/id-photo/#jp-residence-card) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 比护照照片小，而且有自己的数字：⁦30 x 40⁩ 毫米，头高 25 毫米（上下差三毫米），从头发顶端量到下巴，头顶上方留 5 毫米。不戴帽子，无背景、无阴影，六个月内拍摄，背面写姓名。任何情况下都不接受修图，也不接受左右颠倒的照片——手机前置摄像头不特意关掉的话，存下来的正是这种。
- 没公布眼线。这里显示的区间，是头部居中时眼睛会落在的位置——是参考，不是要求，也从不标红。

## 这些数值从哪里来

[转录自 出入国在留管理庁 — 提出写真の規格。2026-09-21 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。](https://www.moj.go.jp/isa/applications/status/photo_info00002.html)

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
