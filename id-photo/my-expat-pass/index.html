# 照片要求：马来西亚外籍人士准证（ESD Online）

Jabatan Imigresen Malaysia, Expatriate Services Division 对这种证件的照片有什么要求，以 2026-09-19 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-19

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦35 x 50⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 60.0% 到 70.0%（⁦30–35⁩ mm） |
| 眼睛高度，从底部量 | 50.0% 到 62.0%（⁦25–31⁩ mm）（参考） |
| 背景 | 纯白 |
| 网上申请用照片 | 至少 ⁦413 x 591⁩ px，JPEG，最多 25.0 KB |

[按这条规定制作照片](https://httcup.github.io/tools/id-photo/#my-expat-pass) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 跟马来西亚护照一样是 ⁦35 x 50⁩ 毫米的相框，头却更大——30 到 35 毫米，护照是 25 到 30——所以一次裁切不能两用。上传文件不得超过 25 KB，这很小，所以这里写出的文件会一直压缩到放得下为止。该页面列出的两种申请都接受白底，蓝底只有其中一种接受，所以这里按白底检查。
- 没公布眼线。这里显示的区间，是头部居中时眼睛会落在的位置——是参考，不是要求，也从不标红。

## 这些数值从哪里来

[转录自 Jabatan Imigresen Malaysia, Expatriate Services Division — ESD Online, Passport Photo Requirements。2026-09-19 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。](https://esd.imi.gov.my/portal/photo-requirements/)

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
