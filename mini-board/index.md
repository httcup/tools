# 极简白板

打开就能画的在线画板：六支彩笔、两档粗细、橡皮、撤销、清空，画完一键导出 PNG。没有图层、没有形状库、没有菜单，专门给「随手涂鸦、讲题演算、线上课示意」这类画完就收的场景。

所有绘制都在浏览器本地 canvas 上，不上传任何数据。

## 用法

1. 点颜色圆点换笔，点粗细按钮切换细/中两档；
2. 画错了点「橡皮」擦掉，或「撤销」回退最后一笔（快捷键 Ctrl+Z / ⌘Z，E 切橡皮）；
3. 「清空」整块白板重来；
4. 「导出 PNG」保存白底图片。

## 提示

- 手机上直接用手指画；平板支持触控笔；
- 页面关闭后画布内容不会保留，要留底先导出；
- 需要画流程图、便签、多对象排版，用 [多功能白板](../multi-board/)。
