# 多功能白板

一块可以平移缩放的画布：画笔、直线、箭头、矩形、椭圆、菱形、文字、彩色便签，随手组合成流程图、草图、头脑风暴墙或讲解配图。支持选中移动、撤销重做、保存工程文件、导出 PNG。

画布内容只存在你的浏览器本地，刷新自动恢复，不上传任何数据。

## 用法

1. 工具栏选工具：选择/画笔/直线/箭头/矩形/椭圆/菱形/文字/便签/橡皮/平移；
2. 滚轮缩放，空格（或中键）按住拖动平移，点「适应内容」把视野拉回全部内容；
3. 「选择」工具点选对象拖动移动，便签双击改文字，Delete 删除；
4. 「导出 PNG」按内容自动裁边导出高清白底图；「存工程 / 开工程」保存或恢复画布数据。

## 快捷键

- 工具：V 选择、P 画笔、L 直线、A 箭头、R 矩形、O 椭圆、D 菱形、T 文字、N 便签、E 橡皮
- Ctrl+Z 撤销、Ctrl+Shift+Z 重做、Delete 删除选中、空格+拖动平移

## 提示

- 箭头末端自动带箭头帽，常用来连流程框；菱形适合判断分支；
- 便签双击编辑文字，文字超宽自动换行；
- 随手涂几笔不想管排版，用更轻的 [极简白板](../mini-board/)。
