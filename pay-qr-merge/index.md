# 微信支付宝收款码拼接

把微信收款码和支付宝收款码拼成一张图：上下或左右排版、自动裁掉多余白边、带「微信支付 / 支付宝」标签与分割线，可选圆角卡片和标题文字，导出 1000 / 1600 / 2400px 的 PNG，打印出来贴柜台就行。

图片只读进当前页面的 canvas，合成不上传。

## 用法

1. 分别点两张卡片，选择微信收款码和支付宝收款码的截图；
2. 选排版（上下 / 左右）、导出尺寸、背景色；
3. 需要的话去掉标签、分割线或圆角，填一句说明文字；
4. 右侧实时预览，点「下载 PNG」保存，或直接「打印」。

## 提示

- 这是排版工具，不是「融合码」：两张码画在同一张图上，扫码时仍需分别用微信、支付宝去扫；真正的「一码通用」得走支付机构的聚合码服务；
- 每张图只放一个二维码，不要把两张码截在同一张图里；
- 合成清晰度取决于原图，模糊的话重新保存一张更清晰的收款码；
- 定稿打印前先自己扫一遍，确认能识别；
- 经营场所记得定期检查二维码有没有被替换。
