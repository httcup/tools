# 隐私与 Cookie

本站是一个纯前端的本地工具箱：所有文件处理都在你的浏览器里完成。本页说明哪些数据会离开你的设备、存了什么、由谁处理。

最后更新 2026年10月28日

## 你的文件

你选来处理的文件，在你设备上的浏览器里读取、编辑和写出。本站没有接收文件做处理的上传端点，也没有存放这些文件的数据库；下载内容在本地组装。

本地处理不会把以下内容交给本站：

- 你的文件和预览
- 文件名、大小、尺寸或格式
- 文件内容，包括 EXIF、GPS 和识别出的文档文字

每页的 `Content-Security-Policy` 限制允许加载的资源和连接目的地。少数工具会连接下面列出的第三方服务，页面内有各自的说明。

你用工具做出来的文件，交给的是你浏览器自己的下载机制，存到哪里由你决定，这一步本站不参与。

## 主动使用连接的功能

以下工具只有你主动操作时才会联网，平时打开页面、处理文件都不发请求。

**[图片转视频](https://httcup.github.io/tools/images-to-video/)**：填写图片网址导入时，那台服务器会收到你的 IP 地址和完整请求 URL。图片到达后只在本地内存中处理，不会发送你从设备上选择的文件。

**[收据与发票提取](https://httcup.github.io/tools/receipt-invoice-extractor/)**：照片和文字识别全部在本地完成。可选的「历史汇率」按钮会向 Frankfurter（frankfurter.dev）请求货币对和你选的日期，对方只会看到你的 IP 和这个请求，收据内容不会发送。手动填汇率则完全不联网。

**配对工具**（[文本与文件分享](https://httcup.github.io/tools/share-text/)、[分享浏览器标签页](https://httcup.github.io/tools/share-tab/)、[远程摄像头](https://httcup.github.io/tools/remote-camera/)）：把文字、文件、画面或摄像头视频经加密连接传给你批准的另一台设备。建立连接需要经过引见服务器，它能看到房间代码、IP 地址、时间和连接协商消息，看不到传输内容；使用中继方式时，Cloudflare 会转发加密流量并保留约七天的连接元数据日志。没有你的批准，对方看不到任何内容。

## 被收集了什么

- **没有广告**：本站不接入任何广告服务。
- **没有访问统计**：部分页面保留了一个统计脚本模板，但未配置任何统计服务 ID，它不会向任何服务器发送数据。
- **捐助按钮**：少数页面上有 Buy Me a Coffee 捐助按钮，由他们的服务器加载，加载时对方会看到你的 IP 和你访问了本站；不点击它就不会有后续。
- **托管**：本站托管在 GitHub Pages 上。和任何网站一样，托管方会处理你的浏览器发出的请求（IP 地址、请求的页面、user agent），用于把页面送到你手上和保障服务可用。本站拿不到托管方的逐访客日志。

## Cookie 与本地存储

本站不设置登录或会话 Cookie，没有账号系统。

部分工具使用浏览器本地存储（localStorage）记住你的数据，例如「随手记存为.md」把笔记内容存在当前浏览器里。这些数据不发送给本站或任何第三方，只存在你这台设备上；清理浏览器的站点数据会删除它们。**请注意：不同域名之间互不相通**，如果你用多个域名访问本站，各自域名下保存的笔记等本地数据是相互独立的。

## 你对这些数据的权利

本站不持有你处理的文件，也没有账号、订单或个人资料可查。上面说明的托管请求日志由托管方按其政策处理。
