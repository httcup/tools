# 二维码生成和美化

把链接或文字做成拿得出手的二维码：8 种点阵骨架（经典、圆角、圆点、液态、线条、竖线、菱形、花瓣）、4 种定位点形状、前景渐变与角度、透明背景、内嵌标志（自动切到 H 级容错），导出 PNG（最高 4096px）或无限放大的 SVG。

所有二维码都在浏览器里生成，内容不上传。样式会自动保存在当前浏览器里。

## 用法

1. 在左侧输入要编码的链接或文字；
2. 挑点阵样式和定位点形状，调颜色（可开渐变）、边距；
3. 需要的话上传一张小图当标志，尺寸可调；
4. 选导出尺寸，下载 PNG 或 SVG。

## 提示

- 内嵌标志会自动把容错等级切到 H，装不下的内容会提示缩短文字；
- 美化过的二维码对比度可能下降，导出后先扫一遍确认能识别；
- 前景浅、背景深的配色多数扫码器读不出来。

来源参考 [httcup/qraft](https://github.com/httcup/qraft)（其形态参考 QRBTF 的独立实现），本站按零依赖方式重新实现，编码使用站内自带的 qrcode-generator 本地副本。
