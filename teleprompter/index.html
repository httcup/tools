在线提词器

把口播稿、演讲稿、直播话术贴进来，点「开始提词」就按设定速度匀速滚动。字号、行宽、速度、黑白配色、左右/上下镜像都能调，空格暂停、方向键调速，手机平板横竖屏都好用。文字只存在你自己的浏览器里。

快捷键：空格 开始/暂停 · ↑ ↓ 字号 · ← → 速度 · Esc 退出 · F 全屏

怎么用更顺

  • 把稿子按「一句一行」排好，滚动时更容易跟读，不要长段落挤在一起。
  • 开始前先调字号，站得远就调大，手机自拍杆支架上 48–72px 比较合适。
  • 用提词器 App 的双面镜（分光镜）拍摄时，勾上「左右镜像」，画面里的字才是正的。
  • 滚太快跟不上的话，按 ← 减速；临时要说题外话，空格暂停就停住。
  • 提词时把浏览器切到全屏（F 或 F11），地址栏不会占地方。

稿子不出本机

文字只写进当前浏览器的 localStorage，不上传、不同步，换设备或清理浏览器数据就没了，重要稿子记得自己另存一份。

没有时长限制

滚动速度按字号自动折算成像素，长稿短稿都能用；全部是本地 CSS 动画推进，不依赖网络。
