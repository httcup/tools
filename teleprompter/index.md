# 在线提词器

把口播稿、演讲稿、直播话术贴进来，点「开始提词」就全屏匀速滚动。字号、行宽、速度、倒计时、黑白配色、左右镜像、上下倒置都能调，空格暂停、方向键调速。

所有内容只写进当前浏览器的 localStorage，不上传、不同步。

## 用法

1. 在编辑区贴入稿子，一段一行（空行会渲染成段落间距）；
2. 调字号（站得远就调大）、行宽、滚动速度（按「字/分」计，默认 240）；
3. 需要倒计时就设 3 秒，点「开始提词」，倒数结束自动滚动；
4. 提词中按空格暂停/继续，← → 调速，↑ ↓ 调字号，Esc 退出，F 全屏；
5. 用双面镜（分光镜）拍摄时勾「左右镜像」，画面里的字才是正的。

## 提示

- 稿子按「一句一行」排，跟读更顺；长段落挤在一起容易看串行；
- 速度按当前字号和行宽折算成像素/秒，改字号后实际滚动节奏会跟着变；
- 文字存在浏览器本地，换设备或清理数据就没了，重要稿子自己另存一份；
- 只在本地推进动画，不依赖网络，断网也能用。
