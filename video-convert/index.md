# 全能视频格式转换

把视频丢进来，转成 MP4 或 WebM、按 1080p / 720p / 480p 压缩、改帧率与码率、只截一段、变速、旋转翻转、去掉声音，或者只把音轨提取成 WAV。

转码用浏览器自带的编码器在你的设备上完成，文件不上传。

## 用法

1. 选择或拖入视频，等浏览器读出时长和画面尺寸；
2. 选输出格式（WebM / MP4 / 只提取音频）、分辨率、帧率、码率；
3. 需要剪一段就用「起点设为当前 / 终点设为当前」，或者直接填秒数；
4. 按需改变速、旋转、翻转、音量，点「开始转换」；
5. 转完点「下载文件」。MP4 能否输出取决于浏览器是否自带 H.264 编码（选项里会标出）。

## 提示

- 浏览器只有实时录制接口，所以转换用时约等于片段时长（2 倍速减半）；期间别切到后台，容易掉帧；
- 输出上限 1920 长边，4K 源会自动降到 1080p，避免卡顿；
- 无损转封装（`-c copy`）、AVI/MKV 输出、CRF 精调这类需求请用桌面 FFmpeg；
- 只提取音频时输出的是无损 WAV，和「在线音频剪辑」正好接得上；
- 转完先播一遍确认画面方向和声音都正常，再删原文件。
