# 网页文章截图

把公众号文章、网页正文转成一张排版干净的长图：全文复制粘贴进来（支持富文本 / Markdown / 纯文本，自动识别标题、段落、引用、列表），或输入链接自动抓取正文，导出高清 PNG 直接转发。

排版渲染全部在浏览器 canvas 里完成，不上传。

## 用法

1. 「粘贴正文」：全文复制粘进正文框，标题、来源随手填；
2. 「输入链接抓取」：贴公众号文章链接，经公开只读代理取回正文文本（失败就回粘贴模式）；
3. 选宽度（750 公众号 / 900 / 1080）、主题（素白 / 纸黄 / 夜读）、字号，实时预览；
4. 「下载 PNG」保存（2x 高清导出）。

## 提示

- 公众号图片有防盗链，抓取与粘贴都只取文字排版，做的是干净纯文字长图；要保留图片请整页截图；
- 链接抓取走 r.jina.ai 公开代理，仅用于换取公开网页的正文文本；
- 片尾署名可在选项里关掉。
