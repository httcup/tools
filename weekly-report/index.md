# 周报生成器

把流水账排成一份像样的周报：按「本周完成 / 下周计划 / 问题与需要的支持」三节填条目，右侧实时排出带日期、带编号的成稿，一键复制或下载 Markdown / 纯文本。

填写内容自动存在浏览器 localStorage，下次打开接着写，不上传任何数据。

## 用法

1. 每节点「＋ 加一条」，逐条写；空章节可以留空（默认不输出）；
2. 右侧实时预览，标题自动带本周一到周日的日期，可填署名；
3. 选项里可关日期、关编号、让空章节也输出；
4. 「复制」直接粘到聊天工具或邮件，「下载 .md / .txt」留底。

## 提示

- 条目写「动作 + 结果」：如「上线退款流程改造，退款时效从 48h 降到 6h」；
- 「问题与需要的支持」一节写具体的人和时间点，比「有困难」有用；
- 换电脑不共享草稿，重要内容记得下载留底。
